# 电工技能大赛理论题库练习

黑龙江省机场集团电工技能大赛 · 理论题库练习（离线可用 / PWA 可安装）。

## 题库规模

| 题型 | 题数 | 说明 |
|---|---|---|
| 选择题 | 199 | 原文档缺第 146 题 |
| 填空题 | 96 | 编号 1-96 连续，前 5 题为文档附录 5 题 |
| 判断题 | 260 | 完整 |
| **合计** | **555** | 全部配有解析 |

## 功能

- 📝 练习三种题型，支持顺序 / 随机出题
- 📑 题号卡片：绿=已答对、红=答错过、灰=未做，点题号直接跳转
- 📒 错题本：答错自动收录，答对自动移除
- ⭐ 收藏本 + 题目收藏按钮
- 🎓 背题模式：不作答，随时查看答案+解析（不判分、不计错题）
- 📝 组卷训练：把错题 / 收藏拼成试卷集中练
- 🔧 实操任务书：评分标准（按附件4原文）+ 模拟接线练习 + 实物参考图
- 💡 每题解析：做题前可点「💡 解析」随时查看
- ☁️ 多端同步：Gitee 仓库 / GitHub Gist / JSON 文件，三种任选
- 📱 PWA：部署到 https 后可安装为手机 / 电脑 APP，离线可用

## 本地使用

下载 `电工技能大赛题库练习_安卓离线版.html`（单文件，完全离线），
用手机 Chrome 打开即可，可添加到主屏幕。

电脑使用：解压后双击 `index.html`；或运行 `python3 start.py` 起本地服务。
