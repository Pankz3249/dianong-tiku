【★ 🎓 背题模式（不作答，只看答案）】
适合想"快速过题、记忆答案"的场景（比如坐车、排队时）。
- 开启：在题目下方勾选「🎓 背题模式」（与"答对后自动下一题""立即显示答案"
  两个选项并排）。开关状态会记住，下次打开仍是背题模式。
- 开启后：
  · 主按钮从「提交答案」变为「👁 查看答案」，点一下即显示本题答案 + 完整解析；
  · 选择题：正确答案标绿高亮，同时显示"X. 选项内容"；
  · 填空题：答案自动填入输入框（只读），并列出各空答案；
  · 判断题：显示 对（√）/ 错（×）并高亮正确项；
  · 题目下方有黄色提示条说明当前处于背题模式。
- 关键：<b>不判分、不计入错题本、不影响答题进度与统计</b>。
  背题就是背题，不会污染你的练习数据（题号卡片的绿/红标记不变）。
- 关闭：取消勾选即恢复正常答题模式。

【★ ☁️ 多端同步（三种方式任选）】
在「☁️ 多端同步」面板顶部有三个切换按钮，任选其一，互不影响：
  · GitHub Gist
  · Gitee 仓库（新增，国内速度快）
  · JSON 文件
同步内容均相同：错题本 + 收藏本 + 答题进度。

方式一 · Gitee 仓库（推荐，国内快）
  1) 获取令牌：Gitee → 设置 → 私人令牌 → 生成新令牌 → 勾选 projects 权限
  2) 在面板切到「Gitee 仓库」，填：令牌 + 用户名 + 仓库名（如 dianong-sync）
     + 文件路径（默认 sync.json）
  3) 首次点「🆕 自动建仓库」：自动创建私有仓库并上传初始数据
  4) 日常同步：一端点「⬆️ 上传」，另一端点「⬇️ 拉取」
  数据以 sync.json 存在你的 Gitee 私有仓库里。

方式二 · GitHub Gist
  1) 获取 Token：GitHub → Settings → Developer settings → Personal access
     tokens → Generate new token (classic) → 只勾选 gist 权限
  2) 填 Token + Gist ID（首次可留空自动新建）
  3) 点「⬆️ 上传 / ⬇️ 拉取」

方式三 · JSON 文件（完全离线，不用账号）
  A 设备点「导出 JSON」→ 文件发到 B 设备 → B 设备点「导入 JSON」选中即合并。

🔒 令牌/Token 仅保存在本机浏览器 localStorage，只与 Gitee / GitHub
   官方 API 通信，不经过任何第三方服务器。
💾 不配置任何同步也能正常使用，数据存在本机。

【★ 📝 组卷训练（错题 / 收藏 集中练）】
顶部新增「📝组卷」标签，可以把错题本、收藏本拼成一份试卷来练。

可配置四项：
  ① 题源：错题本 / 收藏本 / 错题+收藏（合并去重）/ 全部题目
     —— 每个题源按钮上直接显示当前可用题数
  ② 题型：选择题 / 填空题 / 判断题（可多选，默认全选）
  ③ 题量：全部 / 20题 / 50题 / 100题
  ④ 顺序：按顺序 / 随机打乱

用法要点：
  · 点「▶️ 开始训练（N 题）」生成试卷，进入答题
  · 题干左侧会标【选择题】【判断题】等，因为一份卷子里混合了多题型
  · 题号卡片显示"卷内序号"，鼠标悬停可看原始题号
  · 点「🔄 重新组卷」回到配置页换一套
  · <b>答对的错题会自动移出错题本</b>，练完一卷错题就少一批
  · 组卷是临时试卷，不写"上次做到第几题"，不影响正常刷题进度

典型用法：
  · 赛前突击：题源=错题本，题量=全部 → 一气呵成清错题
  · 每日一练：题源=错题+收藏，题量=20，随机 → 20 题小卷
  · 专项突破：题源=错题本，题型只勾判断题 → 专练判断薄弱点

【★ 填空题里多出来的空是怎么回事（已修复）】
有些题会莫名其妙多出几个空（比如第28题出现3个空、第29题6个空）。
原因：文档里空白处是用下划线字符 ___ 画出来的，而这些下划线字符
所在的文字块本身也是「加粗 + 带下划线」的，于是被误判成了一道空。

例如第28题原文：
  ____电荷____有规则的移动…，电流的方向规定为__正电荷_____运动的方向。
其中 __ 这类纯下划线也被当成答案，导致答案变成
  [电荷, __, 正电荷]（3个空）—— 正确应为 [电荷, 正电荷]（2个空）。

修复方式：同一个空常被拆成好几个文字块，先合并相邻的文字块，
再按连续下划线切开，只保留真正的答案文字。
  例：__ + 正电荷 → 合并 __正电荷 → 切分 → 正电荷

现已全量校验：102 道题的「空位数 == 答案数」全部吻合，
且没有任何答案里残留下划线或纯标点。

【★ 填空题的编号与答案（重要说明）】
本套填空题的原题在 Word 文档里有两种排版写法，早期版本只读对了其中
一部分，导致"答案空位"识别不全。现已全部修正：

答案（填空处）在文档里用三种方式标示，软件都能识别：
  ① 加粗 + 字符样式"Hyperlink"（样式自带下划线）
     —— 例如第 8 题的「干粉」「1211」「二氧化碳」
  ② 加粗 + 直接下划线
     —— 例如第 57 题的「安全操作程序」
  ③ 只加粗，旁边用下划线字符（___）画出空白
     —— 例如第 58 题的「线圈」「动铁心」「静铁心」

  出现 96→100→101 的跳号与重复题号。
  现按你的要求重排为：
    · 前 5 题 = 文档开头的附录 5 题（巡视四方法 / 四把关 / 四对照 /
      五清 / 技术措施），与文档阅读顺序一致；
    · 第 6 题起 = 原正文内容，去掉与附录重复及正文内部完全重复的题；
    · 最终共 96 道，编号 1-96 连续，无跳号、无重复、无题干编号前缀。

【★ 更新后看不到新功能怎么办（重要）】
每次更新后，如果页面还是老样子（比如没有「📝组卷」标签），
说明浏览器加载的是缓存里的旧文件。按下面顺序处理：

1. 看页脚版本号
   页面最底部会显示「当前版本：20260918a」。
   如果版本号不是最新的，说明确实是旧文件。

2. 点版本号强制刷新（推荐）
   直接点页脚那个红色版本号 → 确认 →
   会自动清空浏览器缓存、注销 Service Worker 并重新加载。
   这是最彻底的方式，一次就好。

3. 手动强制刷新
   按 Ctrl + F5（Mac 用 Cmd + Shift + R）。

4. 仍然无效 → 换目录重新解压
   把新压缩包解压到一个全新的文件夹再打开，
   不要用旧文件夹（旧目录里可能残留旧文件）。

原因说明：本工具带 Service Worker（用于离线使用），
早期版本采用「缓存优先」策略，会直接返回本地旧文件而不去
服务器取新内容。现已改为网络优先：联网时总是取最新，
断网时才回退到缓存。同时新增版本检测：发现版本变化会
自动清缓存刷新一次，以后更新会自动生效。

  方式是把全部文件推送到 GitHub 仓库，开启 GitHub Pages
  （Settings → Pages → Enforce HTTPS），即可获得形如
  https://<用户名>.github.io/<仓库名>/ 的地址，手机访问该
  地址即可安装为 APP 并自动启用多端同步（同一 URL）。

【运行方式（本地）】
1. 解压本压缩包到任意目录（路径建议纯英文，避免中文/空格）。
2. 运行 start.py（需 Python 3）：
       python3 start.py
   · 默认尝试 8000 端口；若该端口被占用，会自动顺延到 8001、
     8002…直到找到可用端口，并在启动信息中提示。
   · 服务绑定局域网（0.0.0.0），启动后会同时打印"本机访问地址"
     与"手机访问地址（需与电脑连同一 Wi-Fi）"，方便手机练习。
   · 若端口被占用导致启动失败，可先关闭占用程序，或改用：
       python3 -m http.server 8080
     再访问 http://localhost:8080 。
3. 按提示在浏览器打开 http://localhost:8000（或自动切换后的端口）
   即可离线练习。
   也可直接双击 index.html 用浏览器打开（核心练习/错题本/模拟
   接线均可使用；PWA 安装与多端同步建议通过 start.py 启动）。
