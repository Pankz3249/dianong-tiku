☁️ 多端同步（错题本 + 答题进度）

💡 填入 GitHub Personal Access Token（勾选 gist 权限）与 Gist ID 即可跨设备同步。
💡 Gitee 同步说明：数据以 sync.json 文件存在你的 Gitee 仓库里。
· 首次使用点「🆕 自动建仓库」，会自动创建私有仓库并上传初始数据（令牌需勾选 projects 权限）。
· 日常同步：一端点「⬆️ 上传」，另一端点「⬇️ 拉取」即可。
· 令牌获取：Gitee → 设置 → 私人令牌 → 生成新令牌 → 勾选 projects。
💡 离线同步（无需账号）：在 A 设备点「导出 JSON」得到文件，用微信/QQ 发到 B 设备， 在 B 设备点「导入 JSON」选中该文件即合并。完全不联网、不依赖任何平台。
📱 手机安装 APP：Android Chrome 打开会自动提示"安装"；iPhone 请用 Safari 打开 → 点右上角 分享 → 添加到主屏幕。
🔒 隐私说明：Token / 令牌仅保存在你本机浏览器的 localStorage 中， 本工具只向 GitHub 或 Gitee 官方 API 发送数据，不经过任何第三方服务器。
💾 不配置任何同步方式也可以正常使用，数据保存在本机（关掉浏览器再打开仍在）。
🎓 背题模式：点上方「👁 查看答案」即可看答案与解析；不判分、不计入错题本、不影响答题进度，适合快速过题记忆。
