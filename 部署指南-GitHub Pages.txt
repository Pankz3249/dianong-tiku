=====================================================================
电工技能大赛题库练习 · GitHub Pages 部署指南
（网页手动上传方式，全程不需要安装任何软件）
=====================================================================

【为什么换成 GitHub Pages】
Gitee Pages 已经下线（官方明确回复"服务已下线，暂无上线计划"）。
GitHub Pages 免费、稳定、自带 https，且你已有 GitHub 账号，
是目前最省事的替代方案。

⚠️ 关于国内访问速度：
GitHub Pages 在国内访问有时会慢。但本工具是 PWA，
一旦在手机上"安装成 APP"，所有资源会缓存到本地，
之后打开基本不走网络 —— 这个短板被规避掉了。
首次打开慢一点，装完就一直是快的。


=====================================================================
【准备工作】
=====================================================================

只需要一样：GitHub 账号（你已有）。

不需要实名认证，不需要备案，不需要信用卡。
也不需要给我任何密码或 Token。


=====================================================================
【第一步：新建仓库】（约 2 分钟）
=====================================================================

1. 登录 https://github.com
2. 右上角「+」→ New repository
3. 按下面填写：
   · Repository name（仓库名）：dianong-tiku
     建议就用这个 —— 它就是你网址的最后一段
   · 选 Public（公开）
     —— GitHub Pages 免费版对公开仓库开放，私有仓库要付费
   · 勾选「Add a README file」
   · 其他（.gitignore、License）都不用选
4. 点「Create repository」

创建完地址栏类似：
    https://github.com/你的用户名/dianong-tiku


=====================================================================
【第二步：上传文件】（约 3 分钟）
=====================================================================

1. 把本压缩包解压，打开 github_pages 文件夹
2. ⚠️ 重要：是打开文件夹，把【里面的文件】上传，
   不要把 github_pages 这个外层文件夹本身传上去
   （否则网址会多一层 /github_pages/ 路径）
3. 在仓库主页点「Add file」→「Upload files」
4. 把文件夹里所有文件（16 个）一起拖进浏览器窗口
   （可以全选后一次性拖）
5. 等上传进度条走完
6. 页面底部「Commit changes」区域：
   · 上面填一句提交说明，比如「上传题库文件」
   · 选「Commit directly to the main branch」
7. 点绿色的「Commit changes」

上传完仓库里应该能看到这些（必须齐全）：
    index.html                 ← 主页面（最关键）
    data.js                    ← 题库数据 555 题
    app.js                     ← 程序逻辑
    sw.js                      ← 离线缓存
    manifest.webmanifest       ← PWA 配置（决定能不能装成 APP）
    icon-192.png
    icon-512.png
    icon-192-maskable.png
    icon-512-maskable.png
    ref_photo1.jpg ~ ref_photo3.jpg      ← 实物参考图
    ref_comp1.jpg  ~ ref_comp3.jpg
    电工技能大赛题库练习_安卓离线版.html   ← 供手机下载的单文件版
    使用说明.txt
    部署指南-GitHub Pages.txt（就是这份）
    README.md

⚠️ 常见错误：把外层文件夹也传上去了。
   正确：仓库根目录直接就是 index.html
   错误：/github_pages/index.html


=====================================================================
【第三步：开启 GitHub Pages】（约 2 分钟，自动部署）
=====================================================================

1. 在仓库主页，点顶部的「Settings」（设置）
2. 左侧菜单往下找，点「Pages」（在 Code and automation 分类下）
3. 在「Build and deployment」区域：
   · Source 选「Deploy from a branch」（从分支部署）
   · Branch 选 main（或 master，看你仓库默认分支），
     右边目录选 /(root)
   · 点「Save」保存
4. 页面顶部会提示部署中，等 1-3 分钟
   （GitHub Pages 是自动部署的，比 Gitee 省事，不用手动点更新）
5. 部署完成后页面顶部会显示绿色提示，网址是：
       https://你的用户名.github.io/dianong-tiku/
   点开就能用了！

如果几分钟后还是 404：
   · 回到 Settings → Pages 刷新看看有没有变成绿色「Your site is live」
   · 确认 index.html 在仓库根目录


=====================================================================
【第四步：手机安装成 APP】（重点！）
=====================================================================

安卓手机（Chrome）：
1. 手机 Chrome 打开 https://你的用户名.github.io/dianong-tiku/
2. 通常会自动弹出「安装应用」横幅 → 点「安装」
   没弹的话：点 Chrome 右上角「⋮」菜单 → 「安装应用」
   （若是「添加到主屏幕」，效果一样，点它即可）
3. 桌面出现「电工题库」图标，点开全屏运行
4. ★ 装完后资源缓存在本地，之后打开很快，也不需要网络

iPhone（Safari）：
1. Safari 打开网址
2. 点底部「分享」→ 向下找「添加到主屏幕」→ 添加

电脑（Chrome / Edge）：
打开网址后地址栏右侧出现「安装」图标，点一下即装成桌面应用


=====================================================================
【第五步：多端同步（三种方式，任选）】
=====================================================================

在网页底部/同步区找到「☁️ 多端同步」面板，顶部有三个切换标签：

── 方式一 · Gitee 仓库（推荐，国内 API 快）──
⚠️ 注意：Gitee Pages 虽然下线了，但 Gitee 的【仓库和 API】仍在，
   所以这个同步方式完全可用，不受影响 —— 它存取的是仓库里的
   sync.json 文件，跟网页托管是两回事。

  1) 获取令牌：Gitee → 设置 → 私人令牌 → 生成新令牌
     → 勾选 projects 权限
  2) 面板切到「Gitee 仓库」，填：令牌 + 用户名 + 仓库名
     （如 dianong-sync）+ 文件路径（默认 sync.json）
  3) 首次点「🆕 自动建仓库」：自动创建私有仓库并上传初始数据
  4) 日常：一端点「⬆️ 上传」，另一端点「⬇️ 拉取」

── 方式二 · GitHub Gist ──
  1) 获取 Token：GitHub → Settings → Developer settings
     → Personal access tokens → Tokens (classic)
     → Generate new token → 只勾选 gist 权限
  2) 面板切到「GitHub Gist」，填 Token + Gist ID（首次可留空）
  3) 点「⬆️ 上传 / ⬇️ 拉取」

── 方式三 · JSON 文件（完全离线，不用账号）──
  A 设备点「导出 JSON」→ 把文件发到 B 设备
  → B 设备点「导入 JSON」选中即合并

三种方式并存，随时切换。同步内容相同：错题本 + 收藏本 + 答题进度。
令牌/Token 仅存本机浏览器，只与官方 API 通信。

⚠️ 换网址后记录不会自动跟过来：
   新网址（github.io）和原来的本地文件，浏览器是分开存储的。
   按上面的方式导出/导入 JSON 迁移一次即可。


=====================================================================
【以后怎么更新题库】
=====================================================================

GitHub Pages 是自动部署的，比 Gitee Pages 省事：

1. 在仓库里更新文件（上传新版 index.html / data.js / app.js）
2. 等 1-3 分钟自动生效 —— 不用手动点任何"更新"按钮

手机上如果还是旧内容：
  · 点页面最底部那个红色版本号，强制刷新一次
  · 或手机 Chrome 长按刷新按钮选「清空缓存并硬性重新加载」


=====================================================================
【常见问题排查】
=====================================================================

Q1：网址 404
  · 确认 Settings → Pages 显示绿色「Your site is live」
  · 确认 index.html 在仓库根目录，不在子文件夹
  · 网址末尾要有斜杠：.../dianong-tiku/
  · 首次部署等 3 分钟再试

Q2：页面能开但白屏 / 没样式
  · 文件没传全，对照上面清单检查，尤其 data.js 和 app.js

Q3：手机不弹「安装应用」
  · 确认网址是 https:// 开头
  · 用 Chrome，不要用微信/QQ 内置浏览器
  · 确认 manifest.webmanifest 和 4 个图标都传了

Q4：访问太慢
  · 首次打开慢是正常的，装成 APP 后就走本地缓存了
  · 也可考虑部署到国内平台（腾讯云 EdgeOne Pages 等）

Q5：Gitee 同步还能用吗？
  · 能。同步用的是 Gitee 仓库 API，不是 Pages，互不影响


=====================================================================
【如果 GitHub Pages 访问实在太慢】
=====================================================================

国内备选（需另行注册/实名，流程略长但速度快）：
  · 腾讯云 EdgeOne Pages —— 有免费额度，国内节点快
  · 腾讯云 CloudBase 静态网站托管 —— 子域名免备案
  · Cloudflare Pages —— 免费无限带宽，国内访问中等

这些平台部署的都是同一套静态文件，
本压缩包里的文件可以直接用，只需按对应平台的上传流程操作。
